VibeCal Website — first test version

Open index.html in a modern browser.

Included:
- Today task list
- Add/edit/delete/complete tasks
- Search
- Date/time, priority, difficulty, category, notes
- Recurring tasks
- Daily target
- Monthly calendar with completion colors
- Weekly/monthly statistics
- Streaks and achievements
- Tomorrow list
- Carry-forward unfinished tasks
- Workload indicator
- Light/dark theme
- Browser reminder notification
- Local browser storage

This is a client-side prototype for testing. Data is stored in the browser's localStorage.
